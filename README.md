I'm a versatile Computer Engineering student who moves comfortably across three layers of the modern software stack: **building applications, orchestrating agentic AI systems, and turning data into decisions.**

Concretely, that means I:
- **Develop** full-stack, production-grade applications (web, APIs, desktop)
- **Design agentic AI systems** — multi-agent pipelines, LLM orchestration, RAG
- **Integrate data services into applications** — connecting pipelines, APIs, and databases into working products
- **Apply AI to data analysis** — machine learning and deep learning used to extract real insight from data, not just build models in isolation
